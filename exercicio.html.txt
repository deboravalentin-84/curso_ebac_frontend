            <div class="step">
                <h2>1. Salve seu arquivo HTML</h2>
                <p>Salve o arquivo do formulário HTML na pasta do seu projeto:</p>

                </div>
                <p>Você pode fazer isso pelo Visual Studio Code, usando o menu "File" > "Save".</p>
            </div>
            
            <div class="step">
                <h2>2. Abra o PowerShell na pasta do projeto</h2>
                <p>Para abrir o PowerShell diretamente na pasta do projeto:</p>
                <ol>
                    <li>Abra o Explorador de Arquivos</li>
                    <li>Navegue até: <span class="path">C:\Users\Debora\Desktop\projetos\curso_ebac_frontend</span></li>
                    <li>Clique com o botão direito segurando Shift e selecione "Abrir janela do PowerShell aqui"</li>
                </ol>
                
                <div class="explanation">
                    <h3>Por que usar o PowerShell?</h3>
                    <p>Você só precisa do PowerShell para executar comandos Git que enviarão seu arquivo para o GitHub. O arquivo HTML em si é aberto no navegador, não no PowerShell.</p>
                </div>
            </div>
            
            <div class="step">
                <h2>3. Execute os comandos Git</h2>
                <p>No PowerShell, execute os seguintes comandos:</p>
                
                <div class="command">
                    # Verifique se está na pasta correta<br>
                    git status
                </div>
                
                <div class="command">
                    # Crie e mude para a branch exercicio_html<br>
                    git checkout -b exercicio_html
                </div>
                
                <div class="command">
                    # Adicione o arquivo ao staging area<br>
                    git add formulario-cadastro.html
                </div>
                
                <div class="command">
                    # Faça o commit do arquivo<br>
                    git commit -m "Adiciona formulário de cadastro com nome, email e senha"
                </div>
                
                <div class="command">
                    # Envie para o GitHub<br>
                    git push -u origin exercicio_html
                </div>
            </div>
            
            <div class="important">
                <h2>Importante!</h2>
                <p>O PowerShell é usado apenas para os comandos Git. Para visualizar seu formulário HTML, você deve:</p>
                <ol>
                    <li>Abri-lo no Visual Studio Code</li>
                    <li>Clicar com o botão direito no arquivo e selecionar "Abrir com Live Server" (se tiver a extensão)</li>
                    <li>Ou abrir diretamente no navegador (duplo clique no arquivo)</li>
                </ol>
            </div>

        // Destaque interativo nos comandos
        document.querySelectorAll('.command').forEach(cmd => {
            cmd.addEventListener('click', function() {

                navigator.clipboard.writeText(text)
                    .then(() => {
                        const original = this.textContent;
                        this.textContent = 'Comando copiado!';
                        setTimeout(() => {
                            this.textContent = original;
                        }, 1500);
                    });
            });
